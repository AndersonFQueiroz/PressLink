# TCC-Portf-lio-DJ-Sem-nome-por-enquanto-

Plataforma SaaS que permite a DJs freelancers criarem, de forma autônoma,
um portfólio/press kit digital profissional — sem precisar de conhecimento
técnico ou contratar um desenvolvedor.

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC).
